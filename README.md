# P2-Once-Upon-An-Arduino

Interaction #1: The user must swap the Golden Idol with the sandbag, activating a switch that triggers flashing red LEDs.
Interaction #2: The user must move Indiana Jones to the end of the corridor, activating a switch that triggers a servo to fire arrows.
Interaction #3: The user must move Indiana Jones to the edge of the pit, activating a switch that triggers a servo to make the idol appear to be thrown.
Interaction #4: The user must place the idol onto the bag, activating a switch that triggers a servo to rotate the image of the spear wall, revealing the dead body of Satipo.
Interaction #5: The user must move Indiana Jones to the end of the corridor again, activating a switch that triggers a servo to roll a boulder toward Jones
